# MS Word Practical Assignment

## Assignment Title

**Formatting Practice – Microsoft Word**

### Objective

Create a **2–3 page document** on the topic **“Amazing Facts About the Human Body”** and use the document to demonstrate the MS Word formatting concepts learned today.

---

# Instructions

Type the following content in Microsoft Word and apply the specified formatting wherever indicated.

## Part 1: Title and Basic Formatting

Create the following title at the top of the document:

**Amazing Facts About the Human Body**

Apply:

* Font Type: **Arial**
* Font Size: **20 pt**
* **Bold**
* Center Alignment

Below the title, type:

**Discover some fascinating facts about the human body and how its different organs and systems work together.**

Format this paragraph using a different font type and size of your choice.

---

# Part 2: Text Formatting Practice

Create the following sections.

## 1. The Human Brain

The **human brain** is one of the most complex organs in the body. It controls thinking, memory, movement, emotions, breathing, and many other important functions.

Format selected words in this section using:

* **Bold**
* *Italics*
* Underline
* Different underline styles
* Strikethrough

Try applying different formatting to different words rather than formatting the entire paragraph.

---

## 2. The Human Heart

The heart is a muscular organ that continuously pumps blood throughout the body. An average adult heart beats approximately **100,000 times a day**.

Format the following:

* Make **100,000 times a day** bold.
* Make *heart* italic.
* Underline the phrase **pumps blood**.
* Apply a different **underline style** to the heading.

### Format Painter Practice

Format the heading **The Human Heart** in an attractive style.

Then use **Format Painter** to copy the same formatting to another section heading.

**Do not manually apply the formatting again.**

---

# Part 3: Subscript and Superscript

Create a small section titled:

## 3. Important Scientific Notations

Type the following expressions:

**Water:** H₂O
**Carbon Dioxide:** CO₂
**Oxygen:** O₂
**Area:** 25 m²
**Energy:** E = mc²

Use **Subscript** for the numbers in the chemical formulas.

Use **Superscript** for:

* m²
* c²

Do not simply type the numbers in a smaller font. Use the actual **Subscript** and **Superscript** commands in MS Word.

---

# Part 4: Change Case

Create the following text exactly as shown:

> THE HUMAN BODY IS AN AMAZING MACHINE.

Use **Change Case** to convert it into:

**The human body is an amazing machine.**

Then convert the same sentence into:

**THE HUMAN BODY IS AN AMAZING MACHINE.**

Finally, convert it into:

**the human body is an amazing machine.**

Use the **Change Case** command instead of manually retyping the sentence.

---

# Part 5: Formatting with Format Painter

Create a section titled:

## 4. Quick Facts

Type the following facts:

* The human body has 206 bones.
* The skin is the largest organ of the human body.
* The lungs help supply oxygen to the blood.
* The small intestine is several meters long.
* The human body contains a large amount of water.

Format the first fact with:

* Bold

* Underline

Then use **Format Painter** to apply the same formatting to at least **two other facts**.
